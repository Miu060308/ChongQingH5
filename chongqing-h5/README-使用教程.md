### 使用 / 替换 / 上线 操作教程

> 一句话：**所有需要改的东西都在 `js/config.js` 和 `assets/` 两个地方，其余文件不用碰。**

## 二、本地预览（VS Code 三选一）

### 方法 A：Live Server（推荐）
1. VS Code 里 `文件 → 打开文件夹`，选中 `chongqing-h5`
2. 扩展商店搜 **Live Server** 安装
3. 右键 `index.html` → **Open with Live Server**
4. 浏览器自动打开，改代码保存即刷新

### 方法 B：Python 起服务（无需装插件）
```bash
cd chongqing-h5
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

### 方法 C：Node 起服务
```bash
npx serve chongqing-h5
```

> ⚠ **不要直接双击 index.html 用 `file://` 打开**。虽然本项目也能跑，但部分浏览器会拦截本地资源，建议一律用上面三种方式。

### 手机上看效果（重要）
1. 电脑和手机连 **同一个 WiFi**
2. 查电脑内网 IP（Windows：命令行输 `ipconfig`，找「IPv4 地址」，如 `192.168.1.23`）
3. 手机浏览器打开 `http://192.168.1.23:8080`
4. 微信里看：把地址发到「文件传输助手」，点开即可

## 四、`config.js` 逐字段说明

### 4.1 地标（landmarks）

当前六个地标（与 `config.js` 顺序一致）：

| # | 地标 | 类型标签 | 地图短名（pin） | 拼音（用于素材命名） |
|---|------|---------|----------------|---------------------|
| 1 | 红岩革命纪念馆 | 红色遗址 | 红岩纪念馆 | `hongyan` |
| 2 | 黄山抗战遗址 | 抗战遗存 | 黄山抗战遗址 | `huangshan` |
| 3 | 洪崖洞 | 山地民居 | 洪崖洞 | `hongyadong` |
| 4 | 十八梯 | 传统街巷 | 十八梯 | `shibati` |
| 5 | 山城巷 | 传统街巷 | 山城巷 | `shanchengxiang` |
| 6 | 白象居 | 山地民居 | 白象居 | `baixiangju` |

```js
{
  id: 'hongyan',           // 唯一标识，别重复
  order: 1,                // 点位编号顺序（画面上显示的 1~6）
  name: '红岩革命纪念馆',   // 完整名称 → 显示在信息卡片上
  pin: '红岩纪念馆',        // ★ 地图点位上的短名（3~6 字最佳，超过 5 字自动缩小）
  subtitle: '渝中 · 红岩村',
  tag: '红色遗址',          // 卡片右上角小标签

  // ---- 真实地图导航页用 ----
  lat: 29.5516,            // ★ 真实纬度（高德/腾讯 GCJ-02 坐标系）
  lng: 106.4975,           // ★ 真实经度

  // ---- 首页文创虚拟地图用 ----
  homeX: 14,               // 首页地图上的水平位置（0~100，对应画面百分比）
  homeY: 30,               // 首页地图上的垂直位置（0~100）
  homeIcon: 'assets/img/building-hongyan.jpg',  // ★ 首页建筑图（同时作卡片主图与问答背景）

  facts: [ { k:'时期', v:'1939—1946 年' }, ... ],   // 卡片顶部数据条，2~4 条最佳
  desc: [ '第一段…', '第二段…' ],                    // 正文，数组里每一项是一个自然段
  thumb:  'assets/img/building-hongyan.jpg',        // 卡片主图（可省略→取 images[0]）
  images: ['assets/img/building-hongyan.jpg', ... ], // ★ 卡片轮播图数组（多张即可滑动）
  video:  'assets/video/hongyan.mp4'                // ★ 舞蹈视频路径
}
```

**卡片轮播图示例**（多张依次展示）：
```js
images: ['assets/img/hongyan-1.jpg', 'assets/img/hongyan-2.jpg', 'assets/img/hongyan-3.jpg'],
```

**首页位置微调**：改 `homeX`/`homeY`（0~100 百分比）；图片丢失会自动降级为编号块。

**替换图片示例：**
```js
images: ['assets/img/hongyan-1.jpg', 'assets/img/hongyan-2.jpg'],
video:  'assets/video/hongyan.mp4'
```

> ⚠ 换地标时别忘了同时改：**`name` / `pin` / `subtitle` / `tag` / `lat` / `lng` / `homeX` / `homeY` / `homeIcon` / `facts` / `desc` / `images` / `video`**，
> 以及下方 `site.intro` 里提到的地标清单与 `quiz.questions` 的题目。
>
> 坐标怎么找：在手机「高德地图」里长按地标正门 → 分享/复制坐标 → 填进 `lat`（纬度）和 `lng`（经度）。
> 六个地标坐标已预设在合理位置，放大到 17~18 级若发现偏移再微调即可。

### 4.2 底部三大板块（site）

- `site.intro.paragraphs` → 「项目简介」弹层的段落数组
- `site.concept.paragraphs` → 「创作理念」弹层的段落数组
- `site.social.links` → 「传播矩阵」的跳转按钮

```js
{ name: '抖音', desc: '舞蹈短片正片', url: 'https://v.douyin.com/xxxx' }
```
`url` 留空 → 点击会提示「链接未配置」（不会报错）。

### 4.3 问答题库（quiz）

```js
quiz: {
  roundSize: 8,     // 每轮抽几题（不能超过题库总数 18）
  shuffle: true,    // true=随机抽题；false=按题库顺序闯关
  questions: [
    {
      from: '洪崖洞',                                  // 右上角显示的地标名，也决定答题背景图
      q: '洪崖洞最具标志性的建筑样式取自哪一种？',        // 题干
      options: ['吊脚楼','四合院','土楼','窑洞'],        // 选项（建议 4 个）
      answer: 0,                                       // ★ 正确选项下标，从 0 开始数！
      explain: '洪崖洞依崖而建，采用干栏式吊脚楼结构…'    // 答对答错都会显示的解析
    },
    // ← 在这里复制粘贴上面这段 {} 就能新增题目，数量不限
  ]
}
```

> 💡 **问答背景图跟随地标**：进入答题后，背景会自动切换为当前题目 `from` 对应地标的图片。
> 程序优先取 `thumb` 字段，其次取 `images[0]`；都没有时显示默认深色渐变占位。
> 只要给地标配上 `images` 或 `thumb`，问答页就会自动出现对应风景背景。

> ⚠ **最易出错点：`answer` 是从 0 开始数的下标。**
> `options: ['A','B','C','D']`，想让 B 正确就写 `answer: 1`。

> 不用刻意把正确答案分散排列：`shuffle: true` 时，程序会在每轮开始时
> 自动打乱每题的选项顺序并重算答案，玩家不会发现「答案总在 A」。
> 若改成 `shuffle: false`，题目与选项都严格按你写的顺序出现（适合录屏 / 固定演示）。

## 五、常见微调

| 需求 | 位置 | 怎么改 |
|------|------|--------|
| 换主题配色（当前为**亮色版**） | `css/style.css` 顶部 `:root` | 改 `--bg-0/1/2`（底色）、`--ink`（文字）、`--gold` / `--gold-2`（主色橙）、`--cyan` / `--teal`（辅助青）。想要回暗色：把 `--bg-0` 改成 `#070b1c`、`--ink` 改成 `#f3f6ff` 即可整体反转 |
| 想换地图底图配色 | `assets/img/map-base.svg` | 文件里所有 `fill=` / `stop-color=` 就是颜色，替换成你们视觉稿的色值 |
| 地图立体感强弱 | `css/style.css` 的 `--tilt` | 默认 `34deg`，改大更俯视、改小更平面；改大后若发现地图上下留白，把 `js/app.js` 的 `TILT_COMP` 同步调小（0.7~0.88） |
| 点位大小 | `css/style.css` 的 `.mk-label` / `.mk-dot` | 改 `font-size` 与 `width/height` |
| 每轮题目数量 | `js/config.js` 的 `quiz.roundSize` | 改数字即可 |
| 关闭随机抽题 | `js/config.js` 的 `quiz.shuffle` | 改成 `false` |
| 底部文案 | `js/config.js` 的 `site` | 见 4.2 |
| 页面标题 | `js/config.js` 的 `meta.title` | 同时改浏览器标签页标题 |

## 八、排错清单

| 现象 | 原因 / 解决 |
|------|-------------|
| 首页地图空白 | `assets/img/home-map.svg` 路径错，或用了 `file://` 打开 |
| 真实地图空白 | `vendor/leaflet/` 路径错，或网络无法访问高德瓦片；建议比赛现场用本地 Leaflet |
| 视频点不动 | 没填 `video` 路径，或文件名/大小写不一致（Linux 服务器区分大小写） |
| 视频有声音但不显示 / 反向 | 视频编码用 H.264/MP4，别用 HEVC、MOV、AVI |
| 改了 config.js 没变化 | 浏览器缓存：手机上长按刷新，或地址后加 `?v=2` |
| 首页地标位置偏移 | 窗口 resize 后自动校准；若仍偏，检查 `homeX`/`homeY` 是否在 0~100 之间 |
| 点位点了没反应 | 刚拖动过地图（有 320ms 防误触），停一下再点 |
| 安卓机型错版 | 用了 `aspect-ratio` / `backdrop-filter` —— 已做降级，但极老机型建议微信内置浏览器演示 |
| 问答一直同一批题 | 把 `shuffle` 改成 `true`，或增加题库数量 |

## 九、技术说明（答辩用）

- **零依赖**：原生 HTML + CSS + JavaScript，无框架、无构建；Leaflet 已下载到本地 `vendor/`，比赛现场无外网也能跑
- **双地图架构**：首页为原创 SVG 手绘文创虚拟山城地图；底部「进入探索」进入 Leaflet + 高德瓦片真实地图导航页，保留缩放/卫星/定位
- **首页地标定位**：JS 根据 `homeX`/`homeY` 百分比 + `object-fit:contain` 实际渲染尺寸，动态校准 marker 容器，保证地标节点与底图对齐
- **真实地图**：六大地标以真实经纬度（GCJ-02）定位，支持 11~18 级缩放、矢量/卫星切换、fitBounds 一键看全
- **手势与性能**：原生 touch 事件 + Leaflet 内置手势；视频 `preload="none"` 懒加载；图片 `loading="lazy"`
- **可维护性**：内容与逻辑彻底分离，运营改内容（文案/图片/视频/题库/链接/首页坐标）零代码改动
- **防作弊**：问答每轮自动打乱题目与选项顺序并重算答案
- **原创合规**：代码、手绘地图底图、建筑图标均为原创绘制，无第三方素材与水印
